# Module 2 — Foundations of Machine Learning
## Advanced track

Welcome. This folder contains your workshop material.

### Start here

Open and run the notebook in order:

1. `01_foundations_of_ml_advanced.ipynb` — the advanced workshop notebook

The setup cell and plot helper are completed for you. Every other code cell contains a `TODO` stub. Read the instructions above each stub carefully before writing your code.

### What you need

No installation is required. All libraries are already available in this environment.

### Duration

Approximately 90 minutes.

### How to work

1. Run the setup cell first.
2. Read the instructions above each `TODO` cell.
3. Write your code in the `TODO` cell and run it with **Shift+Enter**.
4. Fill in the results tables in the markdown cells as you go.
5. Complete the reflection questions at the end.

A reference solution will be made available by the workshop organiser after the session.
