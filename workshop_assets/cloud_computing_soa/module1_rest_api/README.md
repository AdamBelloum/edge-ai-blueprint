# Cloud Computing SOA — Module 1: REST API

This is the participant-asset source for the first Cloud Computing SOA module:
a Flask URL-shortener REST API.

## Tracks

- `beginner/`: guided learning material with complete, explained code.
- `advanced/`: TODO-based Flask implementation exercise.
- `solutions/`: reference implementation; not seeded until an organiser releases it.
- `shared/tests/`: local verification assets used by both participant tracks.

## Runtime boundary

The Flask development server runs only within the participant's JupyterHub
server on `127.0.0.1:5000`. It is tested locally and is not exposed through a
shared ingress or public service.

See `SOURCE.md` for provenance and licence information.

`beginner/app.py` is extracted verbatim from the documented `Complete Final Code (example)` section in `beginner/upstream-participants-guide.md`. The guide remains the pedagogical explanation for that complete, runnable starting point.
