# Module 2 — Foundations of Machine Learning
## Beginner track

Welcome. This folder contains your workshop material.

### Start here

Open and run the notebook in order:

1. `01_foundations_of_ml_beginner.ipynb` — the complete beginner tutorial

All code is completed for you. Read each cell, run it with **Shift+Enter**, and read the explanation that follows.

### What you need

No installation is required. All libraries are already available in this environment.

### Duration

Approximately 90 minutes.

### Online activities

Two browser-based activities are included in the notebook:

- **Teachable Machine** — <https://teachablemachine.withgoogle.com/>
- **TensorFlow Playground** — <https://playground.tensorflow.org/>

If either site is inaccessible, the notebook contains a local Python fallback for the same concepts.
