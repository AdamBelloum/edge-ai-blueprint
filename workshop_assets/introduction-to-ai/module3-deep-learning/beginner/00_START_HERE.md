# Introduction to AI — Module 3: Introduction to Deep Learning

## Beginner track

This is a guided, CPU-only introduction to deep learning. Run the notebooks in
order and execute every cell from top to bottom.

1. `01_from_features_to_neural_networks_beginner.ipynb`
   - inputs, weights, biases, layers, and ReLU;
   - transparent forward passes;
   - linear versus non-linear decision boundaries;
   - a small neural classifier.

2. `02_training_generalisation_and_architectures_beginner.ipynb`
   - training, validation, and test data;
   - underfitting, useful fit, and overfitting;
   - regularisation, early stopping, and gradient intuition;
   - choosing CNNs, RNNs, and Transformers from input structure.

The notebooks use only bundled/generated data and run on the standard workshop
CPU environment. No GPU or internet download is required.

Reference solutions are not included in this track. They are released only by
the organiser after or during the workshop.
