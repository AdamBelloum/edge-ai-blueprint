# Introduction to AI — Module 3: Introduction to Deep Learning

## Advanced track — same workshop, selected coding TODOs

This track has the **same notebooks, dataset, explanations, figures, order,
and learning outcomes** as the beginner track.

Selected implementation steps have been removed and replaced with explicit
`TODO` instructions. Complete a TODO before running cells that depend on it.
The purpose is to practise the implementation details while following the same
introductory deep-learning curriculum; it is not a separate or harder module.

1. `01_from_features_to_neural_networks_advanced.ipynb`
2. `02_training_generalisation_and_architectures_advanced.ipynb`

The notebooks use only bundled/generated data and run on the standard workshop
CPU environment. No GPU or internet download is required.

Reference solutions are not included in this track. They are released only by
the organiser after or during the workshop.
