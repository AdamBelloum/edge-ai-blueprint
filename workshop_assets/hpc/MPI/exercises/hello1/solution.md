# MPI hello world: processes and ranks — reference

This is an introductory example, not buggy code. The reference reproduces the supplied example. Each MPI process executes the same program and has its own rank and address space.

With two processes, expect a greeting from ranks 0 and 1. Output order and line interleaving are not guaranteed.
